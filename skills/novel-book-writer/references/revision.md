# 가독성과 서사 밀도 교정

## 1. 구조를 먼저

각 장을 읽고 '누가 무엇을 원했고, 왜 그 선택을 했으며, 무엇이 바뀌었는가'를 한 줄로 적는다. 답을 만들기 위해 원전 설명이 필요하면 본문을 고친다. 인물이 모르는 정보로 판단한 곳, 장소·시간이 순간 이동한 곳, 갑자기 생긴 해결 능력, 사용되지 않는 장면을 확인한다. 독자에게 일부러 감춘 정보와 작가가 빠뜨린 설명을 구분한다.

## 2. 장면과 감정

주요 선택이 한 문장 요약으로 끝나면 선택의 압력과 대화를 펼친다. 반대로 변화 없는 식사·이동·생각의 반복은 줄인다. 감각은 인물이 알아차릴 이유가 있을 때 남긴다. 몸의 반응·내면 독백·감정 이름표를 매번 함께 써 감정을 세 번 설명하지 않는다. '두려웠다' 같은 짧은 진술도 리듬에 유용하면 허용한다. '보았다/느꼈다'를 일괄 삭제하는 기계 교정은 하지 않는다.

대화의 화자가 바뀌면 문단을 바꾼다. 긴 대화는 동작이나 주변 상황으로 위치를 알려준다. 모든 대사에 이름표·표정·부사를 붙이지 않는다. 조연마다 다른 욕망과 반응을 갖게 하고, 말투의 과장만으로 구별하지 않는다.

## 3. 한국어 문장과 문단

- 주어 생략은 자연스러울 때 유지하되 행동 주체가 바뀌면 이름을 복원한다. '그것·그 일·그 사람'이 앞 문단의 여러 대상을 가리키면 구체어로 바꾼다.
- 한 문장에 원인·회상·반전이 겹치면 핵심 행동을 남기고 나눈다. 짧은 문장만 이어지는 단조로움도 고친다. 긴 문장은 시선의 이동이나 생각의 흐름이 한 방향일 때 사용한다.
- 한 문단은 하나의 행동·관찰·생각 흐름을 중심으로 둔다. 한 줄 문단은 전환을 강조할 때 쓴다. 소설책 전체를 채팅처럼 한 문장씩 떼지 않는다.
- 번역투 피동, '~에 대한/~에 있어서', 불필요한 '~하기 시작했다', 중복 접속어, 명사화와 추상어를 구체적인 동작으로 바꿀 수 있는지 검토한다. 인물의 의도적 어법은 보존한다.
- 새 인명·지명·규칙을 한 문단에 몰지 않는다. 처음 등장하는 대상의 역할을 현재 행동 속에서 알려준다.
- 비유는 장면의 주된 이미지에 집중한다. 물·칼·불의 비유가 한 감정에 겹쳐 이미지를 흐리면 덜어낸다.
- 같은 문장 종결·문단 첫말·손 떨림·심장 묘사가 반복되면 변화를 주거나 삭제한다. 동의어 교체만 하지 말고 반복할 필요부터 판단한다.

수치(문장 길이, 대사 비중, 문자 수)는 의심 구간을 찾는 보조 지표다. 자동 점수로 문체를 균일하게 만들지 않는다. 소리 내어 읽는다는 관점으로 한 문단의 호흡과 대화 구별을 다시 확인한다.

## 4. 원전 없는 독자 검사

원고만으로 다음에 답하고 근거 장면을 기록한다: 주인공의 당장 목적, 주요 관계, 사건의 원인과 책임, 해결 가능한 방법, 최종 선택의 이유, 마지막에 바뀐 일상. 판타지가 아니면 마법 규칙 질문을 생략한다. 검토자가 독립 에이전트인지 집필자 자신의 검토인지, 사람 독자인지 정확히 표시한다.

문제 → 실제 수정 → 다시 읽은 근거의 기록을 남긴다. 사용자가 요청한 분량에서 크게 벗어났다면 근거와 실제 문자 수를 밝히고 분량을 조정한다. 문장만 늘려 목표를 맞추지 않는다.

## 5. 제작 직전

장 순서·호칭·날짜·복선·결말을 최종 대조한다. TODO, 생략 안내, '[본문 작성 예정]' 같은 잔여물이 없는지 확인한다. 대체 결말은 요청된 경우에만 본편 이후의 독립 부록으로 둔다. 원고가 바뀌면 PDF와 목차도 재생성하고 다시 검증한다.
