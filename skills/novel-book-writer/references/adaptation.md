# TRPG·기존 세계의 각색

지정 원전과 최신 확정 결정이 기준이다. 프로젝트별 인물·문서 경로는 사용자의 작업공간에서 찾으며 이 공개 스킬에 특정 비공개 프로젝트를 고정하지 않는다.

- 원전 사실과 창작 보강을 구분한다. 원전의 빈칸에는 직업·일상·관계·갈등을 창작할 수 있다. 확정 사실과 충돌하면 사용자 지정 각색 범위에 맞춰 처리하고 기록한다.
- 주사위·수치·선택지·세션 번호 대신 인물의 판단·실수·준비가 결과를 낳게 쓴다. 실제 플레이 기록이 없으면 특정 회차의 재현이라고 하지 않는다.
- 여러 플레이어의 분산 행동을 독자가 따라갈 시점과 인과로 재구성한다. 인물 합병이나 결말 변경이 허용됐는지 원전 조건을 확인한다.
- 한 경로의 소설이 게임 전체의 정사를 확정하지 않는다. 대체 결말은 별도 요청이 있을 때만 쓴다.
- 마법·특수 규칙은 가능 범위, 한계, 취약 조건, 대가를 구분한다. 해결에 쓸 규칙은 결말 전에 실제 사건으로 보여준다.
- 집필·PDF 제작과 게임 코드 수정·운영 반영·원격 공개를 구분한다. 사용자 원고나 설정을 공개 예제에 자동 복사하지 않는다.

## 플레이 기록에서 장면으로 바꾸기

주사위 숫자와 선택지 표기를 지웠어도 'A가 조사, B가 대화, C가 문 열기, 전원 이동'의 순서만 남으면 여전히 플레이 기록이다. 원전의 **사건 사실**과 플레이 중의 **진행 순서·화면 전환·발언 차례**를 나눈다. 사용자가 보존하라고 한 사실과 인과는 유지하면서, 허용된 범위에서 독자가 따라갈 장면으로 묶는다.

장면마다 한 시점의 목표와 갈등을 중심으로 자료를 고른다. 플레이어 전원의 같은 분량·발언 차례·행동 기여를 본문에 재현할 필요는 없다. 중요한 선택은 당사자가 알아차린 단서, 망설임, 판단의 대가로 펼친다. 반복 이동·실패 판정·아이템 확인·진행 보고는 사건 이해에 필요한 결과만 요약한다. 연속된 세 장면을 같은 비중으로 썼다면 중요도가 실제로 같은지 다시 본다.

장면 메모는 `보존할 사건 / 시점 인물과 당장 목적 / 먼저 알려 줄 상황 / 이번에 소개할 사람 / 결정적인 변화 / 다음 장면으로 가는 이유`로 정리한다. 인물 삭제·합병이 허용되지 않았다면 존재와 핵심 역할을 보존하되 이름 소개와 초점 배분을 나눌 수 있다. 원전의 규칙·은어를 독자도 이미 안다고 가정하지 않는다. 필요한 뜻을 인물이 겪는 구체적인 상황에서 알려 준다.

원전에는 없는 연결 행동과 감정은 창작 보강으로 기록한다. 중요한 동기를 새로 만들면 확정 사실과 충돌하는지 대조한다. 사용자가 원하는 것이 실제 플레이 로그나 대본 형식일 때는 그 형식을 유지하며 소설 문체를 강요하지 않는다.

기존 프로젝트 전용 스킬에 유효한 연속성 체크리스트가 있다면 이 스킬의 장르 조사·가독성·PDF 흐름과 함께 사용한다.
