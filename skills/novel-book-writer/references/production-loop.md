# 장면과 마주 보는 전면 삽화 제작

## 독서 흐름

애니메이션풍 삽화 소설의 기본은 `왼쪽: 장면의 본문 / 오른쪽: 해당 장면의 독립 전면 그림`이다. 다음 쪽에서 본문이 이어진다. 모든 본문 쪽을 그림과 짝짓지 않는다. 감정 전환·장소 발견·중요한 전투에 삽화를 선택하고 장면 수는 브리프에 적는다. 요청한 삽화 수를 표지나 캐릭터표로 대신 채우지 않는다.

삽화 페이지에는 본문·제목·설명·쪽번호를 겹치지 않는다. 한 페이지 전체를 쓰되 얼굴·손·무기·상황 파악에 필요한 배경이 잘리지 않게 원본 비율과 안전 영역을 설계한다. 기본 A5는 148:210 세로 비율이다. 디지털 독서본은 최소 150dpi 상당(약 874×1240px)을 권장하고 인쇄에는 별도 도련·색상·해상도 규격을 확인한다. 해상도만 높여 흐릿한 그림을 합격 처리하지 않는다.

## 장면 원장

각 삽화에 고유 ID, 권/장, 정확한 본문 발췌, 목적, 보이는 인물, 복장, 부상, 소품, 시간·날씨, 행동의 한 순간, 구도, 기준 그림, 프롬프트, 생성 파일, 검수 근거를 둔다. `excerpt`는 그림 맞은편 왼쪽 쪽에 실제로 실릴 짧은 원문 구절이다. 요약문이나 미래 사건을 쓰지 않는다.

캐릭터는 [character-consistency.md](character-consistency.md), 실행 계획은 [visual-plan.md](visual-plan.md)를 따른다. 원고 전체 해시는 주변 맥락 변화까지 감지한다. 코드의 해시 검증은 얼굴·그림의 의미·아름다움을 판정하지 않는다.

## 제작 순서

1. 브리프에 형식, 읽기 방향, 권 수, 분량, 삽화 수와 배치를 적는다.
2. 캐릭터·화풍 기준을 만든다. 기준 그림을 직접 확인하고 `character-bible.json`에 파일 해시를 고정한다. 이후 표지와 장면 그림은 같은 기준을 실제 생성 도구의 참조 입력으로 사용한다.
3. 완결 원고를 집필·개정하고 주요 장면을 고른다. 문단 사이에 `[[art:scene-id]]`를 한 줄로 둔다. 전투 결과·등장인물·부상은 그 위치까지 독자가 아는 범위를 지킨다.
4. 권별 `production.json`을 채운다. 원고·공통 bible의 현재 SHA-256을 기록한다. 원고 변경 후 이전 그림이 재사용 가능해도 기존 검수는 다시 해야 한다.
5. `build_book.py --visual-plan production.json --allow-pending-art`로 조판 초안을 만든다. 그림이 없으면 대기 페이지다. manifest의 `visual_complete`는 항상 false다.
6. 초안의 맞은편 본문을 확인한다. 왼쪽이 비거나 장면 발췌가 없으면 같은 사건 흐름 안에서 앵커를 옮기고 다시 조판한다. 필요하면 더 적절한 장면을 선정한다. 억지 공백·큰 글자·빈 쪽으로 위치나 분량을 맞추지 않는다. 본문을 수정했다면 새 해시와 검수를 갱신한다.
7. 그림을 생성한다. 실제 이미지 생성 도구를 사용하고 기준 그림 경로를 참조 입력에 전달한다. 인물 이름이나 '같은 캐릭터'라고만 적지 않는다. 새 그림마다 얼굴·비율·의상·좌우·무기·지형·행동·스포일러를 직접 본다.
8. 실제 본 뒤 `visual_assets.py record-review`로 검수 사실과 구체적 근거를 저장한다. 프롬프트/원고/기준/그림이 바뀌면 다시 검수한다. 그림을 보지 않고 이 명령을 실행하지 않는다.
9. `--allow-pending-art` 없이 최종 조판한다. 삽화는 홀수 물리 쪽(오른쪽), 맞은편은 해당 본문, 삽화 쪽은 글 없는 전면 그림이어야 한다. 목차 번호·링크·책갈피는 전체 레이아웃으로 다시 계산된다.
10. 전체 페이지 축소판과 모든 삽화 펼침면, 주요 본문 확대본을 직접 확인한다. 본문 누락·한글·목차·인물 연속성을 확인하고 기록한다. 자동 검증과 최종 시각 검수는 서로 다른 완료 항목이다.

## 페이지 방향과 뷰어

LTR 소설에서 표지를 PDF 1쪽(오른쪽)으로 센다. PDF에 `TwoPageRight` 선호 표시를 넣지만 모든 뷰어가 따르지는 않는다. 두 페이지 보기와 표지 단독 표시를 켜고 `왼쪽 짝수 / 오른쪽 홀수`로 확인한다. 합본은 전체 원고와 고유 앵커를 합쳐 재조판한다. PDF를 단순 연결하거나 표지·목차를 임의 제거하면 방향과 링크가 깨질 수 있다.

## 전투 그림

준비 → 접촉 → 결과 중 한 순간을 한 그림에 선택한다. 이동 방향, 무기와 손, 공격 궤적, 방어자, 충돌점, 지면과 거리를 먼저 정한다. 속도선·마력 이펙트로 손·무기·얼굴이 가려지지 않게 한다. 반격이나 부상은 원고 시점과 일치해야 한다. 연속 동작이 필요하면 웹툰/만화 각색에서 패널을 나눈다.

## 변경과 재개

`progress.md`에는 마지막 완성 장, 완성 그림 ID, 미검수/수정 필요 항목, 다음 작업, 실행 명령을 남긴다. 같은 결함은 최대 두 번 재시도한 뒤 구도 또는 방법을 바꾼다. 새 결함 근거 없이 전체를 재생성하지 않는다. 도구 오류·분량 미달·누락 그림은 실제 미완료로 기록한다.

## 구형 하단 방식

사용자가 본문 하단 삽화를 명시한 기존 작업만 `build_book.py --page-art-height-mm 52`와 `page_art.py prepare/apply`를 사용한다. 이 방식은 페이지 추가 없이 예약 사각형에 넣는 호환 경로다. `--visual-plan`과 함께 쓸 수 없다. 새 삽화 소설이나 '오른쪽 전면' 요청을 이 옵션으로 처리하지 않는다.
