# 장편 연속성과 재개

여러 장을 여러 번에 나누어 쓰는 중장편, 여러 권, 중단했다가 이어 쓰는 작업에 적용한다. 단편은 `revision-notes.md` 한 곳에 필요한 만큼만 적는다.

## 파일마다 한 가지 역할

| 파일 | 담는 것 | 갱신 방식 |
|---|---|---|
| `brief.md` | 사용자가 확정한 조건과 제작자의 가정 | 조건이 바뀔 때 |
| `story-bible.md`, `outline.md` | 설계: 앞으로 쓸 계획 | 본문과 달라지면 본문에 맞춘다 |
| `continuity.md` | **본문에 실제로 쓴 사실** | 장을 완성할 때마다 |
| `progress.md` | 지금 상태와 다음 작업 | 매번 **고쳐 쓴다**. 아래에 쌓지 않는다 |
| `revision-notes.md` | 문제 → 수정 → 다시 읽은 근거 | 개정할 때 추가 |

`story_project.py init --format novel`이 이 골격을 만든다(설계 파일과 원장은 `planning/` 아래). 기존 프로젝트에 원장이 없으면 본문을 읽어 `continuity.md`를 만든 뒤 이어 쓴다. 프로젝트마다 형식을 새로 짓지 않는다.

## 연속성 원장에 적는 것

- **장별 기록:** 권·장, 작중 날짜와 시각(첫날부터의 경과일), 장소, 일어난 일 한 줄, 장 끝에서 달라진 것.
- **현재 상태:** 마지막 완성 장이 끝난 시점의 인물별 위치, 부상과 몸 상태, 소지품, 아는 것과 모르는 것, 서로 부르는 호칭. 방의 수와 구조, 함께 있는 인원수, 식량·연료·돈처럼 수량이 있는 것.
- **약속과 회수:** 독자가 본 단서·예고·약속을 심은 곳과 회수할 곳, 현재 상태.
- **고정 사항:** 한 번 나온 뒤 바뀌면 안 되는 날짜, 나이, 거리, 이름 표기, 흉터의 좌우, 과거 사건의 순서.

문장으로 띄어 쓴다. 약어와 기호로 눌러 담은 한 줄은 다음 세션에서 읽지 못한다. 계획했지만 아직 쓰지 않은 일은 원장에 넣지 않는다.

## 장을 완성할 때마다

1. 본문을 원고 파일에 저장한다.
2. 원장의 장별 기록에 한 행을 더하고 '현재 상태'와 '약속과 회수'를 고친다.
3. `story_project.py status`(프로젝트 밖 원고는 `count --manuscript`)로 실제 분량을 확인한다. 분량은 이 수치 하나로만 보고한다. 제목을 포함한 다른 집계와 섞지 않는다.
4. `progress.md`를 현재 사실로 고쳐 쓴다. 마지막 완성 장, 다음 장의 목표·시점·장소, 직전 장의 마지막 상황, 미완료·미검증 항목, 재개 명령.

완성 후에도 '집필 중' 같은 지난 상태 문구가 남지 않게 한다.

## 이어 쓰기 전에 읽는 순서

1. `progress.md` — 어디까지 했고 다음이 무엇인가.
2. `brief.md` — 바뀌면 안 되는 조건.
3. `continuity.md`의 현재 상태, 미회수 약속, 고정 사항.
4. `outline.md`의 다음 장 카드.
5. **직전 장의 마지막 장면 본문.** 요약과 원장만 믿지 않고 실제 문장을 읽어 어조와 마지막 상황을 잇는다.

원장과 본문이 다르면 본문이 기준이다. 원장을 고친 뒤 쓴다.

## 앞 장면을 다시 말할 때

회상, 보고, 증언, 다른 인물에게 하는 설명은 기억으로 쓰지 않는다. 해당 장면의 본문을 열어 **누가, 언제, 무엇을 들고, 무슨 말을 했는지**를 대조한다. 인물이 일부러 다르게 말하는 경우에만 차이를 남기고, 그 의도를 원장에 적는다.

## 묶음으로 쓴 뒤 이음매 검사

몇 장씩 묶어 쓰거나 다른 에이전트에 맡겼다면, 묶음의 경계 앞뒤 장을 이어서 읽는다.

- 이미 소개한 인물·장소·표식을 처음 보는 것처럼 다시 설명하지 않는가.
- 경과일과 시각이 앞 장에서 이어지는가.
- 방과 문의 수, 건물 구조, 함께 있는 인원수가 같은가.
- 버리거나 잃은 물건이 다시 손에 있지 않은가. 없던 장비가 생기지 않았는가.
- '앞의 열두 장에서', '앞서 말했듯' 같은 원고 바깥의 표현이 본문에 남지 않았는가.

집필을 넘길 때는 `현재 상태 + 고정 사항 + 직전 장 마지막 장면 원문 + 다음 장 카드`를 함께 준다. 정정 사항만 길게 적어 넘기지 않는다.

## 설계가 본문과 달라졌을 때

쓰다 보면 본문이 설계를 앞선다. 권이나 큰 단락이 끝날 때 `story-bible.md`와 `outline.md`를 실제 본문에 맞춰 고친다. 이전 판을 남기려면 날짜를 붙인 폴더에 옮긴다. 규칙이나 반전을 바꾸면 영향을 받는 장과 원장의 고정 사항을 함께 고친다.

## 여러 권

- 한 권을 끝낼 때 '약속과 회수'에서 미회수 항목을 뽑아 다음 권 `outline.md`의 첫머리에 옮긴다. 회수하지 않을 것은 '의도적 미해결'로 표시한다.
- 원장은 작품 전체에 하나다. 권마다 인물 상태를 새로 정하지 않는다.
- 다음 권의 첫 장은 앞 권을 읽지 않은 것처럼 전부 다시 설명하지 않는다. 지금 행동에 필요한 관계와 사정만 짧게 되짚는다.
- 삽화가 있으면 부상·소지품·복장의 현재 상태를 `production.json`의 장면 상태와 맞춘다.
