# 캐릭터 일관성: 같은 인물을 다른 장면에 그리기

## 하나의 기준

작품 전체의 `character-bible.json`을 공유한다. 각 권/웹툰/만화 계획은 `bible.path`와 `bible.sha256`으로 이 파일을 참조한다. 파생 형식마다 얼굴을 새로 정하지 않는다. 새 인물을 추가하거나 디자인을 개정하면 버전과 영향을 기록하고 관련 그림을 재검수한다. 기존 그림을 전부 다시 만들 필요는 없지만 변경 기준과 맞는지는 실제로 확인한다.

캐릭터마다 다음을 고정한다.

| 구분 | 필수 내용 |
|---|---|
| 식별 | 짧고 불변인 영문 ID, 이름, 호칭, 나이대, 역할, 체격·신장 관계 |
| 고정 외양 `invariants` | 얼굴형, 눈매/눈색, 머리 모양/가르마/색, 피부, 흉터의 해부학적 좌우, 체형, 특징 |
| 복장 `outfits` | 복장 ID별 형태, 색, 겹쳐 입는 순서, 신발, 장식, 장비와 무기 형태 |
| 기준 그림 `reference` | 직접 확인한 로컬 캐릭터 시트 경로와 SHA-256 |
| 서사 | 말투·욕망·약점·관계·성장 방향은 story-bible에 두고 시각 기준과 모순 없는지 확인 |

기준 시트는 얼굴 확대, 전신, 앞/옆/뒤, 표정, 복장·무기를 알아볼 수 있도록 제작한다. 복잡한 캐릭터는 고해상도 개별 시트를 쓰고 보조 원본은 별도 보관한다. 무리하게 작은 합본 시트에 모든 인물을 넣지 않는다. 인물이 함께 서 있는 키 비교표도 관계 확인에 도움이 된다.

## 장면별로 변하는 상태

각 shot의 `characters`에는 화면에 실제로 보이는 인물만 넣는다. ID, outfit ID, 현재 상태 `state`를 기록한다. 상태에는 들고 있는 물건/손, 장비의 착탈, 젖음·먼지, 부상과 붕대의 위치, 표정과 자세를 필요한 만큼 넣는다. 고정 설정인 흉터와 일시적인 상처를 혼동하지 않는다. 원고에서 치료하거나 옷을 갈아입기 전까지 상태가 이어진다.

좌우가 중요하면 '캐릭터의 왼손(이 구도에서 화면 오른쪽)'처럼 구분한다. 몸이 돌아섰다고 흉터가 반대편으로 이동하지 않는다. 전생 모습과 빙의 후 몸은 별도 디자인/ID로 관리하고, 전생의 얼굴을 현재 몸에 섞지 않는다.

## 생성 입력 계약

이미지 생성 도구의 실제 참조 이미지 입력에 해당 캐릭터 시트를 넣는다. 같은 이름·시드·색상 설명만으로 일관성을 보장한다고 하지 않는다. 도구가 참조 그림을 받지 못하면 그 한계를 기록하고 기준을 전달할 수 있는 경로를 사용한다. 로컬 파일은 먼저 확인하고 지원되는 참조 경로 인자를 쓴다.

프롬프트는 다음 순서로 짧고 구체적으로 작성한다.

1. 용도·비율: A5 오른쪽 전면 삽화 또는 특정 만화 패널.
2. 현재 원고의 장소·시간·행동 한 순간.
3. 보이는 인물과 참조 이미지의 대응, 유지할 고정 외양, 현재 복장·상태.
4. 카메라 위치·인물 배치·움직임/시선·배경 지형.
5. 유지할 화풍과 광원/색, 얼굴·손·무기의 안전 영역.
6. 대사·자막·워터마크를 그림에 생성하지 않고 후속 조판할 것.

기준 시트에 다른 사람이 있더라도 그들을 장면에 모두 출연시키지 않는다. 수정 시 보존할 부분과 바꿀 부분을 분명히 하고 가능한 경우 기존 그림을 편집한다. 한정된 결함 때문에 캐릭터를 새 얼굴로 다시 설계하지 않는다.

## 실제 검수

기준과 장면을 나란히 보고 얼굴/머리/눈/체격, 의상/문양/색, 손/무기/해부학적 좌우, 연속 부상, 조명에 따른 색 변화, 본문과의 행동 대응을 확인한다. 같은 사람으로 보이는지와 정확한 디테일을 함께 본다. 검수 notes에는 구체적 관찰을 적고 불일치는 `revise` 또는 `pending`으로 남긴다.

`record-review`는 이미 한 관찰을 기록하는 명령이다. 얼굴 인식이나 자동 미술 심사를 수행하지 않는다. 코드가 검수 무효화를 감지했다고 캐릭터 일관성을 자동 인증했다고 보고하지 않는다. 최종 조판에서 잘림·작은 얼굴·말풍선 가림이 생길 수 있으므로 원본 검수 뒤 결과물도 다시 본다.
