# 공개 창작 예제의 집필·검토 기록

이 예제는 스킬의 입력 형식과 책 제작을 검증하기 위해 새로 만든 짧은 완결 이야기다. 기존 사용자 소설이나 비공개 TRPG 설정을 포함하지 않는다. 장편 품질 평가의 대체물이 아니다. 저자 표기는 'AI 창작 예제'다.

## 브리프

해안 도시 미스터리 판타지의 정서를 가진 짧은 생활 이야기. 일반 성인 독자, 밀착 3인칭, 편지를 읽는 선택과 새 주소가 생기는 변화가 중심. 대규모 수수께끼 해결이나 강제적인 희생 결말은 목표가 아니다. 죽은 이의 편지라는 설정·집배원과 유가족·철거된 주소의 갈등은 이번 예제에서 창작했다.

## 실제 확인한 자료

확인일 2026-09-21. 두 작품의 **일부 원문만** 확인했다. 전문 완독·모델 재학습은 하지 않았다. 아래 효과는 이번 집필자의 해석이다.

| 작품·출처 | 확인 범위와 관찰 | 이번 예제에서의 적용 |
|---|---|---|
| Wilkie Collins, [The Moonstone](https://www.gutenberg.org/cache/epub/155/pg155-images.html), Project Gutenberg 공개 원문 | Prologue I~IV. 진술자가 관찰한 일과 직접 보지 못한 일을 구분하는 대목 확인 | 서하가 우편의 취급 방법만 알고 유가족의 마음이나 초자연적 전달 조건은 모른다고 인정한다. 특정 작품의 보석·절도·인물·사건을 사용하지 않는다. |
| Algernon Blackwood, [The Willows](https://www.gutenberg.org/cache/epub/11438/pg11438-images.html), Project Gutenberg 공개 원문 | I의 초반: 이동하는 물과 불안정한 지형이 여행의 행동을 제약하는 대목 확인 | 해안의 밀물이 배달 시간과 접근 가능한 장소를 바꾼다. 원작의 강 여행·동행자·공포 존재를 사용하지 않는다. |

원문 인용·번역·작품 파일을 저장소에 재배포하지 않는다. 미스터리/환상 인접 장르의 구조적 기법을 참고한 것이며 두 작품과 같은 문체라고 주장하지 않는다.

## 설계와 연속성

- 서하: 배달 업무를 마치려는 목적 → 수취인이 떠난 주소와 만남 → 과거 약속을 기억 → 형식적 반송 대신 수취인 찾기 → 읽기를 대신하지 않고 곁을 지킴.
- 해주: 아버지의 편지 수령을 미룸 → 사라진 집을 찾음 → 편지를 직접 받음 → 실제 거처의 주소를 씀. 마음을 한 번에 '치유했다'고 결론내리지 않는다.
- 규칙: 죽은 이의 편지는 젖어 도착할 수 있다. 이후 밀물이 닿으면 글씨가 가장자리부터 지워진다. 원래 주소에 가야만 수령한다는 규칙은 없으며 해주의 바람과 구분한다.
- 시간: 아침 배달 → 썰물 때 철거 골목 → 밀물이 들어오기 시작 → 시장 귀환 → 다음 아침.
- 회수: 첫 장의 반송함 → 마지막 장의 주소 변경, 젖지 않은 합격 통지서에 대한 약속 → 손수건, 남겨 두는 우편함 → 새 우편함.

## 교정에서 확인한 항목

- 배달을 계속할 동기는 아버지에게 받은 도움과 지켰는지 모르는 약속으로 본문에 둠.
- 초자연 규칙 설명을 늘리기보다 수취 거부의 감정을 대화로 보여줌.
- 해주의 속마음은 서하의 추측으로 표현하고 전지적 사실처럼 단정하지 않음.
- 서하는 편지 본문을 몰래 읽지 않으며 해주가 말한 내용만 앎.
- 대화 화자 변경 때 문단 분리. 중요한 수령은 장면으로, 귀환은 짧게 처리.
- 자동 완성도 점수는 부여하지 않음. 사람 독자 평가는 아직 수행하지 않음.
