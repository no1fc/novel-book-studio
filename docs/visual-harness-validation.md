# 시각 서사 하네스 검증 — 2026-10-13

## 실제 검증 범위

- `python -m unittest discover -s tests -v`: 26개 테스트 통과.
- `skill-creator/scripts/quick_validate.py`: 스킬 frontmatter/기본 구조 통과.
- Python compileall 및 git diff 공백 검사 통과.
- 독립 사용 검증: 공통 캐릭터 bible을 참조하는 짧은 한글 3권 각각 전면 삽화 2장, 웹툰 3패널을 2개 PNG로 출력, RTL 만화 3패널을 2쪽 PDF/CBZ로 출력.
- 3권의 실제 삽화는 홀수 물리 5·7쪽, 직전 왼쪽 4·6쪽에 본문 발췌가 있으며 삽화 페이지에는 검색 가능한 본문/쪽번호가 없음.
- 목차 표시 번호, 링크, 장 시작, 본문 보존, 전면 이미지 크기 검사.
- 원고/기준/프롬프트/상태/그림 변경 후 오래된 검수 거부, 일부 그림 제작 중 개별 검수 가능, 최종 출력은 미완료 자산 거부.
- 본문·계획·기준·공통 bible의 출력 충돌 보호와 기존 출력 보존, 패널 겹침·읽기 방향 오류·긴 말풍선 거부.
- 표지·목차·본문·삽화의 전쪽 축소판, 실제 펼침면 확대본, 만화 결과, 수정된 웹툰 구간을 직접 렌더링해 확인.

## 독립 검증에서 발견하여 수정한 결함

1. 공통 bible 이름이 출력 manifest와 충돌하면 원장을 덮을 수 있었다. 보호 경로에 bible을 추가하고, 원장/기존 PDF가 유지되며 실행이 거부되는 회귀 검사를 추가했다.
2. 웹툰 PNG 분할 경계에서 패널 사이 여백이 사라졌다. 여백을 실제 픽셀 띠로 보존하고 그림 자체는 자르지 않는다. 폭 800, 높이 1135 패널 3개와 간격 80 두 개의 전체 높이 3565px를 확인했다. 각 파일은 설정된 최대 높이 2400px 이하다.
3. 다른 장면 그림이 아직 없으면 완성된 그림도 검수 기록을 남길 수 없었다. 개별 검수 시 다른 누락 그림을 허용하되 최종 validate/build는 계속 거부하도록 수정했다.

## 검증의 한계

테스트와 독립 사용 검증의 그림은 명시적인 합성 QA 도형이다. 실제 AI 그림 생성·애니메이션풍 품질·캐릭터의 얼굴 일치·문학성·사람 독자 평가는 이번 소프트웨어 검증으로 인증하지 않았다. 실제 작품 제작에서 기준 그림과 장면을 보고 별도로 검수해야 한다.

실행 환경은 Linux, Python 3.14, WeasyPrint 70.0과 한국어 Noto 폰트였다. 인쇄소 납품, 상업 웹툰 플랫폼 업로드 규격, 다른 OS의 폰트 환경, 실제 영상 애니메이션은 검증 범위가 아니다. 웹툰/만화는 검수된 패널과 별도 대사를 합성하는 도구이며 자동 소설 각색·자동 이미지 생성기가 아니다.

오른쪽 삽화의 왼쪽이 비거나 해당 발췌가 없으면 최종 빌더가 거부한다. 현재 앵커 위치를 초안에서 조정하는 작업은 제작자가 수행한다. 자동 판별이 통과해도 잘림·구도·읽는 순서·심미적 품질의 시각 검수는 필요하다.
