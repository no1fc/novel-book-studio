# 삽화 소설·웹툰·만화 제작 하네스

사용자 요구(2026-10-13): 삽화는 본문 하단이 아닌 오른쪽 독립 페이지 전체에 배치한다. 캐릭터를 일관되게 유지하며, 향후 애니메이션풍 소설·웹툰·만화책을 제작할 수 있게 한다. 스킬과 실행 도구를 GitHub에 반영하고 천마 판타지 3부작의 다음 세션용 프롬프트를 제공한다. 이번 작업에서는 소설 본편을 집필하지 않는다.

## 구현 범위

- 기존 한글 A5 빌더와 로컬 최신 집필/표지 개선 사항을 보존한다.
- `visual_assets.py`: 캐릭터 기준·의상·장면 상태·원고·이미지 버전과 검수 증거를 결합한다. 파일이 바뀌면 검수는 무효다. 도구는 시각적 일관성을 자동 판정하지 않는다.
- `build_book.py`: `[[art:장면ID]]` 원고 앵커와 `--visual-plan`으로 독립 오른쪽 삽화 페이지를 조판한다. 기존 하단 모드는 명시적 호환 옵션으로만 유지한다. 두 모드는 혼용 불가다.
- 오른쪽은 LTR, 표지=PDF 1쪽(오른쪽), 홀수 물리 쪽이다. PDF 뷰어의 2쪽/표지 단독 표시를 사용한다. 최종본은 삽화 맞은편 왼쪽 쪽에 해당 장면 본문이 있는지 검사한다. 잘못된 앵커는 초안에서 확인 후 이동한다.
- `build_visual.py`: 검수된 패널을 세로 스크롤 HTML/PNG, 또는 명시적 패널 배치의 만화 PDF/CBZ로 제작한다. 한글 대사·말풍선은 별도 텍스트로 조판한다. 애니메이션풍은 정지 일러스트 스타일이며 영상 애니메이션 제작을 뜻하지 않는다.
- `story_project.py`: 재개 가능한 프로젝트 뼈대와 명시적인 상태 원장, 형식별 계획 양식을 만든다. API/모델을 자동 호출하지 않으며 승인 없는 자동 게시를 하지 않는다.

## 작업 순서 및 완료 근거

- [x] 기존 하단 삽화 동작과 원고 변경 검수 무효화 회귀 확인 (기존 로컬 10개 통과).
- [x] 전면 삽화/목차/본문 보존 및 실패 보호 테스트를 먼저 실행한다.
- [x] 캐릭터 및 장면 버전 검증, 독립 페이지 조판을 구현한다.
- [x] 웹툰·만화 출력과 재개 상태를 실제 작은 입력으로 검증한다.
- [x] 제작 지침·캐릭터 기준·형식 변환·상세 다음 세션 프롬프트를 작성한다.
- [x] 전체 테스트, 스킬 검사, PDF/패널 렌더링과 독립 사용 검증을 수행한다.
- [ ] 설치본 및 로컬 하네스를 동기화하고 GitHub에 커밋한다.
