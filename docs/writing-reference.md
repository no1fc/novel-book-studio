# 이번 개정의 참고 범위

2026-09-21 확인. 사용자가 지정한 [나무위키 소설 작법](https://namu.wiki/w/%EC%86%8C%EC%84%A4%20%EC%9E%91%EB%B2%95)은 직접 열리지 않았다. 실제 열람 자료는 [나무모에 미러의 같은 제목 문서](https://m.namu.moe/w/%EC%86%8C%EC%84%A4%20%EC%9E%91%EB%B2%95)의 「2. 소설 작법의 요점 정리」다. 미러와 현재 원문이 동일하다고 검증하지는 않았다.

참고한 요점은 주제·배경·인물·사건을 연결하고, 인물의 가치관이 행동을 이끌게 하며, 장면을 이해할 정보는 구체적으로 제시하되 한 문단에 몰지 않는다는 것이다. 원문의 예문·항목 전체를 전재하지 않았다. 이를 기존 예제에서 확인된 인과 누락에 대입해, 짧은 사건 줄거리·장면별 선행 정보·본문 근거를 요구하는 독자 검사로 구체화했다. 이 검사 방식은 저장소의 자체 개선안이며 위키가 제시한 검증 도구가 아니다.

사용자 첨부 표지 네 장에서는 인물 중심 전면 삽화, 먹선과 대각선의 움직임, 문양과 중앙 프레임, 절제된 풍경과 제목의 구도를 관찰했다. 원본 이미지·인물·제목·상표는 저장소에 복제하지 않았다. 스킬에는 재사용 가능한 구성 원리만 기록했다. 개정 예제 표지는 저장소의 기존 독창적 AI 삽화를 새로 조판한다.
