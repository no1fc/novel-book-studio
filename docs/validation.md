# 검증 기록

검증일: 2026-09-21. 아래는 실제 실행한 범위이며 문학적 품질 인증은 아니다.

## 기존 지침과 행동 비교

독립 에이전트가 이전 TRPG 전용 스킬로 '원전 없는 해안 도시 미스터리 판타지, 첫 장면 500~700자와 이후 책 제작 절차'를 수행했다. 인과·규칙 안내는 작동했으나 장르 원문 조사 방법, 독창적인 구현으로의 전환, 한국어 가독성 기준, PDF 실행과 시각 검증 방법이 없었다.

새 스킬로 같은 요청과 '자료 접근 불가, 1,200자 현실 로맨스 장면만, 비극·PDF 제외'의 두 시나리오를 수행했다. 실제 장면과 수정 내역을 확인했다. 자료를 읽지 않았다는 사실을 명시하고 장르·요청 범위를 보존했다. 짧은 요청의 파일 생성 범위와 문자 수 기준이 모호하다는 지적을 반영해 수정했다. 이것은 소수의 모의 행동 검사이며 통계적 성능 비교나 실제 사람 평가가 아니다.

## 실행 도구

Linux, Python 3.14, WeasyPrint 70.0, pypdf 6.19.0, PyMuPDF 1.28.2, Noto Serif CJK KR 환경에서 검증했다.

```bash
python -m unittest discover -s tests -v
```

2개 테스트 통과. 검사 내용:

- 46개 장·후기, 긴 한영 혼합 책 제목과 장 제목, 여러 쪽에 걸친 본문·목차.
- 원고 문단 포함, 원고 불변, PDF 제목·저자 메타데이터, SHA-256.
- 각 장의 실제 시작 쪽수, 인쇄된 목차 숫자, 클릭 목적지, 책갈피 일치.
- A5 크기와 페이지 밖 텍스트 없음.
- 빈 원고·빈 장·지원하지 않는 Markdown·원고 덮어쓰기·존재하지 않는 폰트 경로 거부.

테스트를 먼저 실행해 빌더 부재 실패를 확인했다. 긴 표지 제목이 장식과 분리되어 다음 쪽으로 밀리는 문제를 시각 검토에서 발견했고, 실패하는 검사를 추가한 뒤 조판을 수정했다. 명시적 로컬 폰트 옵션도 별도로 실행했다.

## 창작 예제와 PDF

[원고](../examples/manuscript.md)는 본문 2,710자(공백 포함, 장 제목·줄바꿈 제외), 3장, 53문단의 새 창작 예제다. [참고·교정 기록](../examples/research-and-revision.md)에 실제 열람 범위를 남겼다.

- A5 총 9쪽: 표지 1, 속표지 2, 차례 3, 각 장 시작 4·6·8쪽.
- 원고 SHA-256: `8c21b48478b7a04c8f3a652867bc23701d4d1716fdbd7fcba310bb61dd8e0c0e`.
- 53문단 전체가 PDF 텍스트에 같은 순서로 포함됨. 대체 문자·페이지 밖 단어 0.
- 한글 글꼴 임베딩 확인. 실제 목차 링크와 책갈피 목적지 확인.
- 9쪽 전체 축소판 및 표지·목차·본문·마지막 쪽 확대본을 검토. 속표지 부제의 대비를 높이고 다시 렌더링해 확인.

## 남은 검증 범위

사람 독자의 몰입도 평가, 여러 장르 장편의 장기간 집필, Windows/macOS의 네이티브 라이브러리 설치, 모든 에이전트 제품에서의 스킬 로딩은 검증하지 않았다. PDF는 독서용이며 인쇄 납품 규격 검증은 하지 않았다. 삽화 표지를 만드는 이미지 생성 서비스는 기본 빌더에 포함되지 않는다.

## 장르 색감·AI 표지 확장 검증

2026-09-21 후속 요청 반영. 7개 시작 팔레트와 6개 역할별 사용자 색상, 로컬 PNG/JPEG/WebP 표지 옵션을 추가했다. 이미지 생성은 에이전트 도구가 담당하고 빌더는 생성된 그림을 조판한다.

- 기존 2개 검사와 새 2개 검사를 합쳐 4개 테스트 통과. 실제 PDF의 글자·종이색, 표지 이미지 임베딩·해시, 사용자 색상, 낮은 대비·잘못된 색·없는 이미지의 오류 및 기존 출력 보존을 확인했다.
- 70자 한글 제목+부제+그림에서 표지가 두 쪽으로 갈리는 문제를 재현한 뒤 축소 기준을 수정했다. 표지 전체가 한 쪽에 들어가지 않으면 파일을 쓰기 전에 진단한다.
- WeasyPrint 70의 URLFetcherResponse 규약에 맞춰 명시한 로컬 폰트/이미지만 읽도록 갱신했다. [공식 API](https://doc.courtbouillon.org/weasyprint/stable/api_reference.html#weasyprint.urls.URLFetcherResponse)를 확인했다.
- 독립 스킬 적용 검사: '밝은 로맨스, 검은 표지 제외, AI 도구 미연결' 요청에 밝은 팔레트·실행 명령을 구성하고 그림 생성 미완료를 구분했다. 실제 이미지가 없는 상태를 생성 완료로 보고하지 않았다.
- 내장 ImageGen으로 새로운 표지 그림 한 장을 실제 생성해 `examples/cover-coastal.png`에 보존했다. 프롬프트와 시각 확인 기록은 `examples/cover-design.md`.
- `water-mailbox-illustrated.pdf`: 9쪽, 53문단 순서 보존, 한글 글꼴 포함, 대체 문자/페이지 밖 단어 0. 표지·목차·본문 전체 축소판과 대표 페이지 확대 검토. 그림 비율 유지와 제목 대비 확인. 기존 시연 원고·타이포그래피 PDF는 보존했다.

본문 삽화 배치와 모든 장르에서의 사람 독자 평가는 이번 검증 범위에 포함되지 않는다.
