# 소설에서 한 권의 책까지

독자가 장소를 상상하고, 인물의 선택을 이해하며, 다음 장을 읽고 싶어지는 **독창적인 완결 소설**을 만든다. 창작 요청은 원고 완성 후 표지·목차·본문 PDF까지 이어간다. 사용자가 시범 장면·개정만 요청하면 그 범위만 수행한다. 스킬 설치 자체는 기존 소설 전체 개작이나 공개의 허가가 아니다.

## 시작과 작업 크기

기존 원고·사용자 선호를 먼저 읽는다. 장르, 예상 독자, 분량, 시점, 원하는 독서 경험, 각색 원전의 유무를 정리한다. 완결 집필에서는 `brief.md`에, 짧은 시범에서는 응답 안에 둔다. 이미 주어진 내용은 재질문하지 않는다. 비어 있는 항목은 작업을 좌우할 때만 묻고 나머지는 가정으로 표시한다. 기본은 한국어, 밀착 3인칭, A5 독서용 PDF다. 분량은 **제목·Markdown 기호·줄바꿈을 제외한 본문, 공백 포함 문자 수**로 계획하며 PDF 쪽수로 억지로 늘리지 않는다. 다른 계산 기준을 요청받으면 그 기준을 따른다.

- 짧은 시범: 브리프·참고 기법 메모 + 실제 장면 + 검토를 응답 안에서 간략히 처리한다. 별도 파일·원장·PDF는 요청할 때만 만든다. 완결 책이라고 부르지 않는다.
- 단편: 조사·설계·검토를 한 메모에 합쳐도 된다.
- 중장편: 아래 파일을 유지하고 한 장씩 집필·개정한다. 한 번의 출력 한계를 요약으로 메우지 않는다. 중단 시 마지막 완성 장·원장 상태·다음 장 목표를 `progress.md`에 남긴다.
- 기존 원고: 원본 보존, 별도 개정본. 사건을 고정할지 재구성할지는 사용자 요청에 따른다.

## 작업 순서

1. **장르 참고** — [research.md](references/research.md)를 읽고 같은 장르 자료를 직접 열어 비교한다. `research.md`에 출처·읽은 범위·기법·우리 작품의 새 구현을 적는다. 이는 참고 분석이며 모델 재학습이 아니다. 접근하지 못한 원문을 읽었다고 쓰지 않는다.
2. **상상력과 설계** — [fiction-craft.md](references/fiction-craft.md)를 읽는다. 서로 다른 발상 후보를 짧게 비교해 하나를 선택하고, 욕망·갈등·세계의 제약·결말을 인과로 묶는다. `story-bible.md`와 `outline.md`에 연표·지식·복선·장별 변화를 남긴다. TRPG 각색일 때만 [adaptation.md](references/adaptation.md)를 추가로 읽는다.
3. **실제 집필** — 장별 목표·행동·관계 변화가 있는 본문을 `manuscript.md`에 쓴다. 중요한 선택은 대화와 행동이 벌어지는 장면으로 펼치고 이동·반복은 요약한다. 독자가 상상할 구체성을 보강하되 모든 문장을 묘사로 채우지 않는다.
4. **개정** — [revision.md](references/revision.md)에 따라 구조·장면·문장을 순차 교정한다. `revision-notes.md`에 문제 문장/장면, 수정, 확인 근거를 기록한다. 원전 없는 독자 관점에서 이해가 끊기는 곳을 직접 고친다. 점수나 문자 수만으로 문학적 완성도를 인증하지 않는다.
5. **책 제작** — 원고의 결말과 누락 여부를 확인한 뒤 [book-production.md](references/book-production.md)를 읽고 PDF를 만든다. [cover-design.md](references/cover-design.md)에 따라 장르·정서에 맞는 표지와 글자 색을 선택하고, 몰입에 도움이 되거나 요청된 경우 AI 삽화를 생성해 사용한다. 표지, 속표지, 자동 목차, 본문, 요청된 후일담 순서다. 조사·검토 메모는 본문 밖에 둔다.
6. **전달** — 원고, PDF, 실제 읽은 참고 목록, 검토 기록을 전달한다. 미검증 항목과 사람 독자 평가 여부를 구분한다. GitHub·외부 출판은 그 작업에 대한 사용자 요청이 있을 때만 수행한다.

## 완료 판단

완결 책 요청이면 본문이 개요로 대체되지 않았고 결말까지 실제로 쓰였는가? 짧은 시범·부분 개정 요청이면 지정 범위를 실제 본문으로 완성했는가? 인물의 결정과 결말의 결과를 설명할 수 있는가? 참고 작품의 고유 사건을 이름만 바꾸어 옮기지 않았는가? PDF를 요청받아 제작한 경우 목차·한글·본문 누락·시각 검사를 했는가? **각 검사를 실제 수행한 범위로만 보고한다.**
