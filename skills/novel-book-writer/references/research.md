# 장르 참고를 창작 판단으로 바꾸기

## 찾고 읽기

장르·정서·독자층이 가까운 2~4개 작품을 출발점으로 삼되 작은 시범은 1~2개로 줄인다. 출판사 미리보기, 작가가 공개한 발췌·창작 인터뷰, 합법 공개 원문을 우선한다. 서평은 독자 반응의 근거이며 원문을 읽었다는 근거가 아니다. 한 작품에만 기대지 말고 서로 다른 기법을 비교한다.

웹 접근이 가능하면 실제 페이지를 열어 확인한다. 검색 결과 요약만으로 문체·장면을 분석하지 않는다. 접근할 수 없다면 사용자가 제공한 발췌나 확인 가능한 자료만 사용하고, 자료를 확보하지 못한 부분은 '일반 장르 지식에 기반한 가설'로 표시한다. 이 경우에도 창작은 진행할 수 있지만 '작품 분석 완료'라고 보고하지 않는다.

## 짧은 연구 카드

작품별로 다음을 기록한다.

| 필드 | 필요한 내용 |
|---|---|
| 출처 | 제목, 작가, 원문/미리보기/인터뷰/서평 구분, URL 또는 제공 파일 |
| 확인 범위 | 확인 날짜, 실제 읽은 장·쪽·절. 일부 발췌면 일부라고 명시 |
| 관찰 | 해당 범위의 시점 거리, 정보 공개 순서, 장면 속도, 대화 또는 감각의 기능 |
| 추론 | 그 장치가 독자에게 주는 효과. 관찰 사실과 구분 |
| 새 구현 | 우리 인물의 직업·욕망·환경에서 같은 기능을 다른 사건으로 만드는 방법 |
| 차별화 | 옮기지 않을 고유 인물·세계·사건 조합과 우리 작품의 차이 |

줄거리 요약보다 '기법 → 효과 → 새로운 구현'을 남긴다. 예: 환경의 변화가 이동을 방해해 긴장을 만든다는 기법을, 새로운 작품에서는 소금 때문에 고장 나는 우편 수송 장치와 배달 지연으로 구현한다. 참고 작품의 섬·인물·결말을 그대로 옮기지 않는다.

## 활용 범위

'학습'은 이번 집필을 위한 독서·분석이다. 모델 가중치를 바꾸거나 영구 학습시켰다고 말하지 않는다. 긴 원문이나 유료 전체 책을 수집·재배포하는 대신 출처와 자기 말로 쓴 기법 메모를 보관한다. 공개 열람 가능성과 재배포 허가는 구분한다. 사용자 제공 원문도 공개 저장소에 자동 포함하지 않는다.

특정 현역 작가의 문체를 그대로 재현하기보다 '절제된 대화, 가까운 시점, 일상 속 불안, 느린 정보 공개'처럼 일반적인 특성으로 바꾼다. 번역문에 기대는 경우 번역자의 문장 선택과 원작의 구조를 구분한다. 세부 문장·이름·상징·사건 순서가 특정 작품에 집중되면 초고를 다시 설계한다. 이것은 법률 판정이나 표절 탐지 인증이 아니라 창작 검토다.
